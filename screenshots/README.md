agar dapat dirujuk dari PDF dan matriks keterlacakan.

Aturan singkat:

- Ambil dari aplikasi yang **benar-benar berjalan**, bukan dari desain Figma.
- Ukuran jendela seragam (1366×768 atau 1440×900), zoom 100%, playlist data konsisten.
- Sertakan bilah alamat pada minimal satu screenshot sebagai bukti aplikasi berjalan.
- Jangan menampilkan kata sandi, token, atau data pribadi nyata.
